# Messaging Modernization Workshop

Materials and hands-on exercises for migrating from JMS brokers (including TIBCO and IBM MQ) and Solace to NATS.

## Workshop materials

| Material | Description |
| --- | --- |
| [Workshop presentation](materials/CompetitiveWorkshop_Oct_2026.pdf) | October 2026 presentation |
| [Migration Workshop Hands-on Lab](materials/Migration%20Workshop%20Hands-on%20Lab.pdf) | Participant lab guide |
| [Download the lab files](materials/migration_workshop.zip?raw=true) | ZIP containing the workshop configurations, scripts, and command reference |

## Getting started

1. Read the requirements in the hands-on lab guide and install the required tools.
2. Download and extract `migration_workshop.zip`.
3. Open a terminal in the extracted `MigrationWorkshop` directory.
4. Follow the lab guide. Use `workshop_instruction.md` in the extracted folder as the companion command reference.

The exercises cover subject filtering, accounts and permissions, partitioned consumer groups, and leaf-node topologies.
